# CleanSlot

CleanSlot is a fullstack web application developed as a school project.

The project is built with React, TypeScript, Tailwind CSS, Node.js, Express and SQLite.

## Tech Stack

### Frontend
- React
- Vite
- TypeScript
- Tailwind CSS

### Backend
- Node.js
- Express
- TypeScript
- tsx
- CORS
- dotenv

### Database
- SQLite
- better-sqlite3

### Installation:

1. Clone repository
2. cd client
3. npm install
4. cd ../server
5. npm install

Start frontend:
cd client
npm run dev

Start backend:
cd server
npm run dev

You can verify your installations with:

```bash
node --version
npm --version
git --version
```
